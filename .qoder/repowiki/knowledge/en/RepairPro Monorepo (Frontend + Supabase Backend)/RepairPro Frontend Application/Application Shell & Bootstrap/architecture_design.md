The module is the application entry point split across four files. `src/main.tsx` creates the React 18 root via `createRoot`, wraps `<App />` in `HelmetProvider`, imports global styles and i18n, then calls `registerServiceWorker()` from `./lib/swUpdate`. `src/App.tsx` composes the top-level provider tree (`QueryClientProvider`, `AuthProvider`, `TooltipProvider`, `ImpersonationProvider`, `ShopSettingsProvider`, `BrandThemeProvider`, `NotificationsProvider`) around a `react-router-dom` `BrowserRouter`/`Routes` tree, declares all public and protected routes (with `ProtectedRoute` and `AuthUpdateGate` guards), and lazy-loads every page through a local `lazyWithRetry` helper that clears a stale-session guard on success and triggers at most one hard reload on first chunk-load failure before falling back to retry. `@tanstack/react-query` is configured with a 5-minute stale time and 15-minute cache lifetime. `src/sw.ts` is the single Workbox service worker (built via `vite-plugin-pwa`'s `injectManifest`): it precaches the app shell, uses `NetworkFirst` for HTML navigations (excluding `/~oauth`, `/api`, `/functions`), applies `StaleWhileRevalidate` with expiration to heavy lazy chunks matching a specific asset pattern, handles web push notifications and notification clicks, and activates immediately via `skipWaiting` + `clientsClaim` so the in-app update flow can reload into the new build. `src/index.css` defines the Tailwind-based design system (CSS custom properties for light/dark themes, animations, landing-page glassmorphism, thermal-print media queries). `src/vite-env.d.ts` simply references `vite/client` for Vite-generated types.
