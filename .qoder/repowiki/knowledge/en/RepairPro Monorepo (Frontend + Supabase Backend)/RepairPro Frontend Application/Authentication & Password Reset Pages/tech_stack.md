React + TypeScript pages built on Supabase JS client (`@supabase/supabase-js`), React Router v6 (`useNavigate`, `useLocation`, `useSearchParams`), TanStack Query (`useQueryClient`), Framer Motion (`AnimatePresence`, `motion`) for step transitions, lucide-react icons, shadcn/ui primitives, and Supabase Edge Functions (`signup-guard`, `request-reset-code`, `verify-reset-code`, `update-password-with-token`, `grant-trial`, `notify-admin-signup`). hCaptcha integration via `@hcaptcha/react-hcaptcha` when `VITE_HCAPTCHA_SITE_KEY` is set.
