Requires environment variable `VITE_HCAPTCHA_SITE_KEY` to enable invisible CAPTCHA on the registration form; without it the captcha widget is skipped. The reset flow expects Supabase Edge Functions `request-reset-code`, `verify-reset-code`, and `update-password-with-token` to be deployed, and the email link handler must exchange a PKCE code via `supabase.auth.exchangeCodeForSession`.
