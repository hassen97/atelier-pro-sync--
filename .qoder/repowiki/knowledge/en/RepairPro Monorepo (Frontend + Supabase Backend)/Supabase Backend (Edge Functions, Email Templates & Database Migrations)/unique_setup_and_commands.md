Each Edge Function is deployed via the Supabase CLI using the `config.toml` manifest under `supabase/`; functions requiring JSX must include a local `deno.json` with `jsx: 'react-jsx'` and `jsxImportSource: npm:react@18.3.1` (see `auth-email-hook/deno.json`). Migrations are applied with `supabase db push` from this directory. Required secrets at runtime include `SUPABASE_URL`, `SUPABASE_SERVICE_ROLE_KEY`, `LOVABLE_API_KEY`, and `RESEND_API_KEY` (for the transactional queue).
