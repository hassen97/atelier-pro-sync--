The repo is split into two cooperating subsystems: a Vite/React frontend (`frontend_app`) served as a single-page app via `vercel.json` rewrites, and a Supabase backend (`supabase_backend`) providing Edge Functions, SQL migrations, and Resend-powered email. The frontend connects to the backend exclusively through Supabase's JS client using `VITE_SUPABASE_*` env vars defined in `.env`, so both sides share the same Supabase project URL and anonymous key. Build-time wiring lives in `vite.config.ts` (SW precaching, chunk splitting for Three.js, PWA manifest injection) and `tsconfig.json` (project references across `app`/`node`), while runtime routing is handled by `react-router-dom` on the client and Supabase Edge Functions on the server — there is no shared code between children; they communicate only over HTTP/Supabase RPC.
